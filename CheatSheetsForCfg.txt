#CheatSheets

# Объяснение значений.
# hold - зажать.
# tap - одно нажатие.
# spam - быстро нажимать.
# parallel - выполнять несколько действия одновременно.
# Более подробные инструкции смотри в разделе "Типы действий".

# Типы действий в SEQUENCE:
#   ("cursor", x, y, пауза_после)                        - переместить курсор и ждать. "x, y," это координаты. (0 = 0 мс, 1 = 1 с, 5 = 5 с).
#   ("tap",    клавиша, раз, пауза_после, удержание)     - нажать N раз (пауза и удержание: 0 = 0 мс, 1 = 1 с, 5 = 5 с)
#   ("hold",   клавиша, секунды)                         - зажать клавишу на N секунд (0, 1, 5...)
#   ("spam",   клавиша, секунды, нажатий_в_сек)          - быстро кликать N секунд
#   ("wait",   секунды)                                  - пауза (0, 1, 5...)
#   ("parallel", действие, аргументы...)                 - параллельное выполнение соседних строк


#   ("parallel", действие, аргументы...)         - то же действие, но идущее одновременно
#                                                  с соседними "parallel"-строками.
#   Подряд идущие "parallel"-строки запускаются вместе; следующая обычная строка
#   ждёт, пока закончатся все. Пример:
#       ("parallel", "hold", "w", 10),
#       ("parallel", "tap", "space", 5, 2),
#       ("wait", 1),                 # начнётся после того, как закончатся обе
#   (старая форма ("parallel", [действие, действие]) тоже работает)
#
# Одновременное нажатие клавиш - через "+":  "w+space", "ctrl+shift+a"
#   ("hold", "w+shift", 10)   - бежать вперёд 10 секунд (W и Shift вместе)
#   ("tap", "w+space", 2)     - W и пробел одновременно, 2 раза
#


# Список клавиш
# Клавиши: "w", "a", "s", "d", "1", "space", "shift", "ctrl", "alt", "enter",
#          "tab", "esc", "up", "down", "left", "right", "f1".."f12"
# Мышь:    "mouse_left", "mouse_right", "mouse_middle"
